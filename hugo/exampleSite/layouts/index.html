Document Skeleton

The shared baseof.html structure. Standardizes head assembly and layout blocks.

The theme provides four named blocks for customization:

  • head: For site-specific head tags (e.g., MathJax)
  • header: To override the default sv/header
  • main: The primary content area (this section)
  • footer: To override the default sv/footer
  • body-end: For dialogs, templates, and scripts at the end of body
